## ⚡ Destaque: Telektro

[**Telektro**](https://telektro.com.br) é um SaaS de gestão de recarga de veículos elétricos, em produção e com cliente real.

- Painel web e app instalável (PWA) para casas, condomínios e eletropostos
- Gateway **OCPP 1.6J** próprio (WebSocket) para conversar com carregadores de vários fabricantes
- Início e parada remota, sessões, medições e cobrança por **Pix** e cartão
- Multiempresa com Postgres + Row Level Security (Supabase)
- Código: [redeeletrogo-a11y/telektro](https://github.com/redeeletrogo-a11y/telektro)
